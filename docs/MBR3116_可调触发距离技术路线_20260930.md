# MBR3116 可调触发距离与悬空误触治理技术路线

日期：2026-09-30。范围：主维护变体 `Nyanithm_firmware_hw_v1`，PCB 感应电极上覆约 2–3 mm 磨砂亚克力。用户报告整片滑条在上方约 5–10 mm 容易触发。

本轮先独立分析官方资料、源码和设备，再比对旧 round88 研究及 round89 计划。本文是后续实施依据；本轮未修改固件、面板或芯片持久化配置。文中区分已验证事实、待验证效果和工程建议。

## 1. 结论与优先路线

当前还不能认定 3116 原生设置已经耗尽。三片芯片虽然读回手动 Finger Threshold=200，但 `DEVICE_CFG2=0x68`、`ATH_EN=1`，手动阈值并未接管判定。**第一项有价值的后续实验是单变量关闭 ATH，再实测触发和释放边界**，而不是继续提高未生效的阈值。[官方 TRM §1.5.9–24、§1.5.60](https://www.infineon.com/assets/row/public/documents/30/57/infineon-cy8cmbr3xxx-capsense-express-controllers-registers-trm-additionaltechnicalinformation-en.pdf)

这只是已确认的配置生效问题，不等于已经证明它是全部隔空触发的根因，也不意味着关掉 ATH 就能保证零悬空。

推荐同时推进两条可汇合的主线：

1. **原生配置与可分性验证**：定位实际通道 → 采集不同手姿、距离及轻触分布 → ATH 单变量 A/B → 判断是否存在稳定区分空间。
2. **持续信号门设计**：对可用的全通道信号持续计算零点、满点和 ON/OFF 门限；用户的禁止触发边界必须覆盖开始、保持、释放以及邻格 slide 快路径。

若标准差值在禁止悬空与轻触时都达到 255，标准差值路线没有区分能力。继续检查 RAW/BASELINE 只能判断是否还有测量信息；要成为游戏方案，还必须解决全通道可达性、扫描延迟及跨重启尺度变化。达不到这些条件就及时转硬件路线。

若要求严格“接触才触发”，优先评估逐区域独立接触确认；若优先保留极轻滑动、多指和现有手感，可评估互电容改板。不能承诺自电容单标量能够在所有手型、湿度、接地条件下测出真实接触距离。

只读定点实验选取 tc16/17/18（0x41:CS7、0x40:CS7、0x42:CS0）。本轮高度是用户目测，未使用量块，不能据此宣称毫米级精度。每阶段约8秒，三个通道交替读取，约5.4次/秒/通道；它是静态诊断，不是同步全板波形。

## 3. 官方接口能做什么

| 原生接口/机制 | 已核实能力 | 对本任务的用途和边界 |
|---|---|---|
| SENSITIVITY0–3，0x08–0x0B | 每电极四档：100/200/300/400 fF | 改增益会改变有效距离；当前已400 fF，没有更低按钮档 |
| BASE_THRESHOLD0/1（0x0C/0x0D）、FINGER_THRESHOLD2–15（0x0E–0x1B） | 按钮模式下逻辑FT0–15，范围31–200；ATH关闭时生效 | 优先确认模式再调阈值；不写越界220/255 |
| HYS override | 范围0–31；ON≥FT+H，OFF≤FT−H | 抑制边界抖动；增H同时使OFF更低，可能抬手更晚释放，不能只看进入距离 |
| 全电极DIFF窗口 | B9=SYNC0、BA..D9差值、DB=SYNC1 | 官方全通道差值读取API能提供一致组；按钮量为归一化0–255 |
| 单ID调试窗口 | DB..E7，RAW/BASELINE/DIFF为16位字段 | 适合观察原始信号；容器16位不保证归一化DIFF超过255 |
| SENSOR_ID | 每次换ID须等待一个实际refresh | 适合定点/慢速校准，不能连续切ID后立即读当实时ADC |
| NT/NNT/LBR、ARST | 基线、环境适应和持续ON复位 | 可研究漂移/长按；不能把悬空吸入基线当作稳定的距离零点 |
| Filter、debounce | 滤除噪声或要求连续扫描确认 | 不提供接触证据；稳定悬空信号不会自然消失，延迟按芯片刷新实测 |
| Proximity、shield、guard | 专用传感配置/电极角色 | 不把32滑条全部变成可独立测距通道；shield并非必然缩短距离 |

依据：[TRM §1.5.5–29、§1.5.103–128](https://www.infineon.com/assets/row/public/documents/30/57/infineon-cy8cmbr3xxx-capsense-express-controllers-registers-trm-additionaltechnicalinformation-en.pdf)，[官方 Host APIs](https://www.infineon.com/dgdl/Infineon-CY8CMBR3xxx_Host_APIs-ApplicationNotes-v09_00-EN.zip?fileId=8ac78c8c7cdc391c017d0723702846a2)。源码已下载到 `_dev_tools/official_mbr_sources/`，应复用其寄存器窗口、等待及同步校验语义，继续调用当前 Pico SDK I2C 层。

有两个必须单独记住的限制：

- 手动FT200、H31时原生ON门槛最多231。若目标禁止悬空已稳定255，继续提高合法FT/H无法拒绝它。原厂同型案例也出现debug DIFF触摸恒255、悬空80–250，而RAW仍有额外变化。[原厂工程师讨论](https://community.infineon.com/t5/CAPSENSE-Multi-Sense/Reading-Debug-difference-count-CY8CMBR3116/td-p/209690)
- Active刷新取完整扫描处理时间与典型20ms的较大者。依官方规则轮换12个调试ID需约≥240ms/片；当前固件每次C7另等40ms，串行读取32车道至少1.28秒。它不能承担快速slide主管线。[Datasheet，Power Consumption and Operational States，纸面p.29/PDF第30页](https://www.infineon.com/assets/row/public/documents/30/49/infineon-cy8cmbr3002-cy8cmbr3102-cy8cmbr3106s-cy8cmbr3108-cy8cmbr3110-cy8cmbr3116-datasheet-en.pdf)

RAW−BASELINE可作为研究信号，不能直接套同单位FT。SmartSense上电会重新选择硬件调谐参数，关闭ATH也不关闭此硬件调谐，绝对RAW标定须跨重启检验。[原厂RAW尺度变化说明](https://community.infineon.com/t5/PSoC-Creator-Designer/CY8CMBR3116-raw-count-hops/td-p/29786)

## 5. 零点、满点和用户调节的准确语义

先定义用户目标：

- **零触发点Z**：在指定禁止位置/姿势及更远距离，最终滑条输出必须为零。包括另一格已接触时、先接触再抬起时。
- **满点F**：用户选定的轻触或近距离状态对应100%归一化信号。此值表示感应强度，并非机械压力，也不自动等于真实接触。
- **触发/释放比例**：在Z与F之间设置ON/OFF，OFF<ON；更高层仍有不可被快路径绕过的Z硬截止。

Z必须取禁止类别信号的保守上界并计入漂移裕量，不能只取所选高度的单次读数或均值；F来自确实命中目标电极的有效接触/近距样本。对可用信号s定义 `u=clamp((s−Z)/(F−Z),0,1)`。只有F−Z超过噪声及环境裕量才接受标定。Z/F同为255、未命中目标电极、接触分布低于悬空上界，均明确报告不可用，不生成貌似可调但实际无效的滑块。

可分性验收按电极/区域和情境计算：

`M = 有效轻触信号下界 − 禁止悬空信号上界 − 额外漂移/测量裕量`

初筛可用轻触低分位与悬空高分位；实际验收还记录最坏样本、误触/漏触次数与试验规模。不能用实触中位数除以单一高度p95的固定比例，宣布所有手势可分。只采集三通道不能证明全板32格可分。

用户填写的“5mm/1mm”应通过量块/间隔片建立每设备、每手姿经验标注；若没有真实测距传感器，只展示估计区间及适用条件。仅两点信号线性化不能推导整个空间中毫米与信号线性对应。

第一版建议：独立二值“接触/近面优先”模式 + 面板归一化显示。HID先保持既有二值契约；游戏原始映射模式另测，不能把任意非零模拟值泄漏成禁止区触发。

## 6. 分阶段实施与停止条件

### P0：证据和仪器，先补测量再调参

本轮已完成：官方原文及Host API获取、设备识别、当前配置备份、ATH状态核实、核心软件盲区审查、部分人在场采样。

下一次采样先用普通模式C5=2/B1与C0三层快照定位被触及车道，再用C7读取同一电极。两次实验分开记录，不能宣称同步；C7固定40ms等待是否覆盖实际refresh，应由成功率/实际数据更新间隔验证。原生一致组同步检查继续保留。

补测矩阵：

| 维度 | 最少内容 |
|---|---|
| 高度 | 无手、10/5/3/2/1/0.5mm、轻接触；高度以亚克力外表面为零 |
| 面积 | 指尖、两指、掌面、双手；轻触和重按分别标注 |
| 位置 | 全部映射车道，特别边缘、中央、逐键210覆盖区域 |
| 历史 | 从远处接近、接触后抬高、同高度停留0–5s/20s/30s、再接近 |
| 音游 | 快速tap、flick、跨格slide、多押、长按、长按旁格悬停 |
| 环境 | 当前USB供电；后续有条件对比电池/充电状态、不同使用者和湿手 |

每组记DIFF、RAW、BASELINE、时间、物理位置、姿势、配置版本、C0层级和最终HID。采样失败和错位不填零；未使能/未映射电极不参与拟合。官方SNR标准另以3000个按实际刷新采集的RAW噪声样本测量，本轮短样本不冒充该测试；长时间接触信号需避开或单独控制20秒auto-reset，记录基线是否追上，不能将复位后衰减当成原本接触信号。

### P1：原生单变量实验，优先ATH生效条件

1. 备份源码/当前可用UF2、B4控制器配置、三片C6全表，并保存哈希。
2. 根据官方定义对**实际读回表**作最小ATH位变更（当前0x68→0x60），不改阈值、灵敏度、auto-reset、地址或供电位；通过既有官方兼容烧录链路和CRC机制处理。不自行生成128B表。
3. 三片逐片保存、复位后128/128复读与CRC校验；失败回滚。用相同位置/手姿/间隔片重测ON与OFF，而不只读取寄存器就宣布修复。
4. 确认手动模式后，在合法31–200范围内选择实际可分区间。HYS另作单变量实验，记录ON升高和OFF降低两种效果。
5. ARST独立观察；长停留导致信号被吸收时可研究关闭后的行为，但不把5秒复位当音游抗悬空默认策略。NT/NNT/LBR和滤波只在有明确漂移/尖峰证据时单独测试。

停止线：标准DIFF在禁止悬空与轻触类别稳定重叠/同为255，原生FT/H和此DIFF的软件门不能产生可靠分离；不继续堆去抖/滤波掩盖。若I2C/配置验证失败，停止该实验并恢复备份，不在失去基准的状态继续调参。

### P2：全通道持续门与两点标定

只读信号路径先对照原厂 `CY8CMBR3xxx_ReadDiffCounts`：用B9..DB一致组及已有I2C STOP-read/Pico SDK API实现有界读取；不另造驱动层，不跨核绕过既有锁。每组三片结果附时间、有效性，确认I2C成本、Core0扫描与ToF/LED/USB并发。

运行门不依赖面板连接或C5会话开关；按真实芯片更新节奏消费数据。对每格持续执行硬截止、ON/OFF滞回和状态清理；邻格连续性只能在硬截止内部提供优化。I2C读失败、陈旧帧不能用于新触发，持续状态设有界安全释放策略。

前期保持BUTTON_STAT候选并用软件门收紧；若用户以后要求扩展更远距离触发范围，需另论证芯片候选门和软件全DIFF判断如何配合。不要把“能抑制到近面”写成“任意毫米量程可调”。

持久化第一版采用统一或每芯片Z/F及小量ON/OFF参数，使用现有36B预留空间内明确版本标记、合法性和默认关闭兼容策略。完整32键Z/F需要64B（8位）或128B（16位），现有预留装不下；后续必须显式设计扩展profile、旧配置迁移和Flash区域边界，保持现有128B配置及CFG_SET帧完整，不默默改变结构大小。

面板负责先定位、采零点、采满点、验证间隔、预览误触/漏触、再应用。回读明确显示ATH/override是否生效，展示原始量和最终判定，去掉未经校准的毫米换算。所有命令沿共享协议与串口事务锁，CFG_SET双写和纯waitForLine不变。

### P3：RAW有信息时的研究支路

若DIFF已截幅但RAW−BASELINE仍明显区分类别，先记录它的重复性和跨复位尺度，再核实原厂是否提供满足全板时效的读取方式。当前公开单ID窗口不满足快速全板扫描，不能直接用轮询32个C7作为游戏门。

允许固定代表电极做机理研究；不以代表键的RAW替全部滑条开总门，多指空间信息不足。没有可接受全通道接口就结束这条运行方案，不通过私有寄存器、伪造resolution表或魔改芯片程序强行实现。

### P4：硬件与独立接触证据

| 顺序/方案 | 目的 | 需要验证的代价 |
|---|---|---|
| 检查亚克力与PCB贴合、内部空气隙/松动 | 提高一致轻触信号，再提高有效门限 | 不保证贴合本身就减少hover；胶需非导电、均匀，先留可逆样件 |
| 小区域电极面积/共面接地/电场约束A/B | 降低远场贡献、增加触摸/悬空间隔 | Cp、SNR、轻擦和边缘slide；不直接给整板铺接地金属 |
| 互电容Tx/Rx改板 | 用更局部的电场保留轻滑动及多点能力 | 新触控IC、电极、驱动和验证；3116不能通过寄存器切成互电容 |
| 逐区域压力/微形变/触点层 | 为真正接触提供独立证据 | 轻滑最小力、相邻区域机械串扰、覆盖层挠曲、耐久和总扫描延迟 |
| 表面接触光学 | 额外感知真实表面接触 | 结构和处理成本高，先样机验证，不作为本RP2040设备首条线 |

若目标是硬性零悬空，逐区域接触层可以与电容位置AND融合或直接作为判定源；**全板单压力开关不可用来保证多指零悬空**，因为一指接触会替另一根悬空手指开门。力传感器还须检查最小启动力与整机轻滑手感。[Interlink FSR400官方参数](https://www.interlinkelectronics.com/fsr-400)

互电容电场通常较自电容局部，是更适合无压力触摸的候选；仍需实际验证其悬空边界。[Microchip PTC原理说明](https://developerhelp.microchip.com/xwiki/bin/view/applications/touch/ptc/)

Driven shield的官方用途可能延长proximity距离，不能直接称为悬空根治。叠层贴合与屏蔽布局须对照AN90071 §4.1、4.2，并用局部样件验证。[官方设计指南](https://www.infineon.com/dgdl/Infineon-AN90071_CY8CMBR3xxx_CapSense%28R%29_Design_Guide-ApplicationNotes-v09_00-EN.pdf?fileId=8ac78c8c7cdc391c017d07236b6e4698)

现有Air ToF/IR只可作为有条件研究项；其视场、遮挡和分区不提供32区域逐指接触证据，不能复用airMin/airMax就宣称滑条已经精确测距。若最终目标转为真实毫米高度量程，需另立空间测距阵列硬件研究，承担视场、亚毫米精度、多指遮挡及延迟验证成本。
