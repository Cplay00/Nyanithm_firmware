## 16位单变量诊断

[原厂TRM §1.5.35](https://www.infineon.com/assets/row/public/documents/30/57/infineon-cy8cmbr3xxx-capsense-express-controllers-registers-trm-additionaltechnicalinformation-en.pdf#page=66)定义0x2E低3位：4为12位，0为16位。[KBA229990](https://community.infineon.com/t5/Knowledge-Base-Articles/Changing-resolution-of-CapSense-proximity-sensor-in-MBR3-does-not-decrease-scan/ta-p/250490)说明Proximity内部始终按16位扫描，低位设置只右移输出。下一轮提高输出精度以排查量化影响，不增加独立物理测量，不宣称提高SNR或缩短扫描。

相较刚完成的ALP OFF/12位候选，仅改0x2E低3位4→0及CRC，其他分辨率、阈值、ALP、ATH、引脚与其他芯片保持。相较普通原表，0x2E回到原值0，实际差异仅：

|地址|原值|实验值|依据|
|---|---:|---:|---|
|0x26|00|01|原生CS0/PS0 Proximity启用|
|0x27|80|00|ALP关闭|
|0x7E / 0x7F|C4 / 96|8C / 65|CRC小端字节，数值0x658C|

候选SHA-256为`24915d67354e245e0e43067bbf1fb31d15758cd54a84faaa1b66255ac1210107`；原表、字段差异及恢复条件见[规格](MBR3116_round89n_16位对照规格.json)。基于实际原表按原厂字段修改，不重新设计128B布局。

新页`http://127.0.0.1:8771/`使用独立Origin、目录和标题，默认食指轻触，尚无实机16位组。下一步同指同点轻触及约3 mm悬空各一组。分析须把参考幅度和远离波动按位数归一比较；显示计数增大不是改善证据。若满输出精度仍无稳定可分裕量，停止单邻格参考的严格接触门控路线；不从偶然分离拟合全板分类器。即便此轮可分，还须不同面积、位置及实时延迟验证，才可实施游戏门控。
