# Nyanithm V1 固件 1.6.6 正式版

发布日期：2026-10-06。适用于 V1 系列原 27 寸、32 寸设备，支持 MPR121 与 CY8CMBR3116 触摸方案。两种尺寸使用同一份 `hw_v1` 固件，各设备保留自己的硬件、灯数、触摸和空气键配置。

## 从 1.6.5 升级的主要变化

- **修复更换硬件后的循环重启。** 外设缺失、初始化失败或硬件选择错误时，启动检查会有界结束，保留配置入口，避免无限告警触发看门狗反复复位。
- **增加上电硬件配置提示。** 检测到触摸方案、布局或空气传感器初始化与配置不符时，全部 LED 红灯闪烁三次：每次亮 2 秒，两次之间灭 0.5 秒，共约 7 秒；随后进入待机。提示不会自动改写配置。出现红灯时，请检查连接和控制面板的硬件选择。
- **提高串口和配置保存稳定性。** 配置、LED、RAW 等指令发生分包、超时或断连时，迟到的数据不会被误当成擦除、重启或刷机命令。慢速读取不会因累积阻塞导致看门狗复位。
- **改进传感器故障处理。** MPR 通信失败不会生成新触摸，已有触摸的故障保持有时间上限；启动校准不能恢复运行状态时会提示异常。ToF 旧锁存结果、无效距离和过期样本不会一直维持空气键。
- **修正逐键设置和附加延迟。** MPR 逐键阈值为 0 时继承全局值，非零值按设置生效；串口输入的 0–15ms 附加延迟按首次观察到的变化计时，并保留已观察到的短按顺序。默认延迟 0 的正常输入行为保持原样。
- **统一正式版本和设备名称。** 版本为 `1.6.6`，去掉 beta；USB 产品及 CDC 接口名称为 `Nyanithm Controller V1`。维护代码统一在 `Nyanithm_firmware_hw_v1` 的 `hw_v1` 分支，兼容性存档停止修改。

## 升级与提示

升级前保存现有配置。按住主控 BOOT 键接入 USB，把 `Nyanithm_V1_1.6.6.uf2` 复制到 `RPI-RP2`；设备会自动重启。控制面板版本查询应显示 `1.6.6`、`hw_v1`、构建号 `round90y-v1-release`。

Windows 可能继续显示缓存的“USB 串行设备 (COMx)”。COM 显示名称由系统设备属性单独保存；本机提供 `tools/update_v1_com_name.ps1`，以管理员权限执行 `-Apply` 可更新指定设备名称并保留 COM 号码。其默认目标仅为本次两台设备，其他设备应显式指定 USB 序列号。接口采用微软支持的 [SetupAPI 设备属性方法](https://learn.microsoft.com/en-us/windows/win32/api/setupapi/nf-setupapi-setupdisetdeviceregistrypropertyw)。

本版不自动生成或改写 MBR3116 的 128 字节 NVRAM 配置表。更换触摸芯片后仍需选择对应硬件；原生信号饱和导致的隔空触发也不能仅凭本次故障处理保证消除。

发布验证包括生产代码故障注入、SDK 编译和两台设备的安装、保存重启回读及连续运行监测。游戏内轻触、滑动、长按和空气键手感仍需实际游玩验收；自动化通过不表示已经覆盖所有硬件组合或断电场景。
