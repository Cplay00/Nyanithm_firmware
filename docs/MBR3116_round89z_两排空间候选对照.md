# round89z：两排空间候选对照

2026-10-02。基底d145468；HW:v2、三片CY8CMBR3116，仍为1.6.6-beta6 / BID round89y。只研究固件和现有寄存器，不使用ToF、不改硬件。

## 结论

不部署这批空间滤波。真实四指相邻按键也形成饱和平顶，宽区域抑制、曲率和突出度会吞合法多押。保守的宽度/原生键数规则没有移除本次有效接触保持段的现有ON，但两次手掌悬空仅改变16/145、3/133个ON观察帧；旧单指悬空全部放过，不能作为稳定解。

这些结果否定本次固定规则的可用性，不证明所有时空分类方法不可能。现有数据仍没有可泛化的全板贴面边界。保留round89y读取改进及round89w成品面板，不写入未经验证的空间门控或“稳定抗悬空”预设。

## 固定规则与布局

用户确认奇偶编号分属两排：15/17/19为同排横向邻格，算法使用索引±2；±1会混入另一排。硬件映射取当前生产代码V1_LANE_M/E。采集前固定七个候选，不按新数据调阈值。

W为全板DIFF>120的格数，N为映射后的BUTTON_STAT ON格数。同排曲率K=2×当前值−左邻值−右邻值，突出度P=当前值−max(左邻值,右邻值)。端点缺失邻格取0，是预定约定，未验证端点安全性。

- 宽区域：W>=4时全抑制。
- 保守宽区域：4<=W<=7且1<=N<=3时全抑制。
- 曲率：W>=4时只保留K>=1、32、64的格。
- 突出度：W>=4时只保留P>=32、64的格。

旧round89x数据仅作探索，按两排布局回放。七种规则均放过食指悬空的38个合格ON观察帧；此前已观察到轻触/食指悬空完全相同的32格DIFF向量。其他传感器使用空间算法的经验不能直接当成本设备的接触证据。

## 五组真机对照

每组两次：两指15/17、三指15/17/19、四指13/15/17/19、手掌轻贴、手掌悬空约5mm。每次保持4秒，固定剔除提示前后0.5秒。五组均完成、网页确认并恢复RAW0；共7376个主机观察帧，7227个32格全合格帧，3个快照复制失败明确排除。观察间隔中位数约20.47–20.51ms。

合格要求PROFILE、复制成功、各片最新DIFF尝试成功且SYNC一致、有好值、BUTTON_STAT有效、格范围有效，好值及整轮年龄均<=15ms。沿用[Infineon TRM的DIFF/SYNC语义](https://www.infineon.com/assets/row/public/documents/30/57/infineon-cy8cmbr3xxx-capsense-express-controllers-registers-trm-additionaltechnicalinformation-en.pdf)。不同芯片顺序读取，C8完成帧不是所有电极同时采样；SYNC一致也不是独立扫描标识。
