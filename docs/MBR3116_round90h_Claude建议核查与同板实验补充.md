**可以采纳“电容响应不是直接的接触/力度真值”和“应检查实际增益、基线、滤波及几何条件”。具体的默认灵敏度比较、接触必陡增，以及简单门限/面积/斜率必能分离，尚无本设备证据；部分建议已遇到实测反例。** 同32寸PCB的模块对照仍为下一步，首先排除映射、模式和基线吸收造成的误解释。

## 逐项裁决

| 建议/解释 | 本设备核查 | 纳入计划的方式 |
|---|---|---|
| 两芯片都测电容变化，不能直接测真实力 | 两者都提供电容感应；MPR也有Proximity，并非MBR独有。具体测量、量程、数字处理不同，不能把两者counts等同 | 保留这个物理边界，目标是稳定触摸输入；连续数值称“电容响应/归一化量”，不标作力值 |
| MBR默认更敏感、MPR默认低且滤波更强 | 不能用型号或默认值解释已定制设备。迁移前MBR启用电极均400fF档；27寸MPR逐电极CDC31–61µA、CDT0.5/1µs、基线跟踪启用 | 保留测量调谐/基线/软件的组合假设，实读每次启动参数；不先指定单一根因 |
| 先关闭接近模式 | 迁移前备份三片0x26均0，PS0/PS1关闭；游戏读BUTTON_STAT和普通按钮DIFF | 作为识别核查项，不重复关位烧表。普通按键仍可响应未接触的电容变化 |
| 继续降灵敏度、提高FT、加迟滞/去抖 | 保存表为最低灵敏度400fF、存储FT200；ATH仍ON，不能说存储FT就是运行阈值。此前手动FT200对照仍有悬空255及原生ON | 已有饱和悬空不能靠重复这组配置解决。迟滞/去抖可能影响释放和响应，需另有假设及慢触/连打验收 |
| 改成读取原始difference，舍弃触摸位 | 当前已读DIFF；MBR按钮DIFF是归一化并截断到255的量，非原始ADC差值。单格RAW/BASE诊断另有接口，不能全板同时读；旧RAW也出现相反标签重合元组 | 保留原生状态与质量校验，RAW仅用于新假设诊断，不以更换字段直接宣称根治 |
| 没有贴面门限，所以固件把DIFF直接当压力 | 普通游戏输出为触摸判定后0/128；迁移前RAW0、cfg2游戏raw位关闭、距离profile关闭。生产准入已有原生位、有效DIFF、确认/保持/故障处理 | 将诊断幅值、原生状态、最终游戏输入分别采集。现有判定仍不保证物理接触，但问题不是缺少一次归一化公式 |
| 在D_hover/D_touch间设T_on，再计算p | 只有相关动作的独立分布有不重叠裕量才能这样做。将d>T_on的标志命名为touched并不获得接触真值；更大的悬空值仍会越过门限 | 先验证可分信息，再考虑映射。低2位未知/削顶/范围和同帧质量保留，不从重合样本拟合“安全”T_on |
| 用面积、相邻计数或峰值/邻道比区分悬空 | round89z四指合法多押为255平顶，曲率/突出度规则拦截；手掌悬空可强且集中，食指悬空也能通过。两排真实邻格索引±2，不能直接按编号±1求物理邻居 | 可作探索特征，不能直接部署旧空间规则；独立多押/slide反例必须保留。这未否定全部多特征方法 |
| 接触一定有陡增，可用斜率 | round90b冻结的1.5 count/ms首次ON规则拒绝慢触原有响应。近面短窗无final ON不等于成功过滤；提示时间不是物理接触时间 | 不重试同一斜率门限。接触变化是否有稳定新特征需实测，慢触和快速悬空分别验收 |
| 调基线，只在无触摸时更新 | 有必要研究；MBR原生已有噪声阈值控制的基线冻结，但“无触摸”本身依赖门限，慢接近/慢触尚未ON时可被吸收。27寸慢触晚窗ELE8基线676–684、0/85 ON；另两片/HID未采 | 同板覆盖三片，区分原厂基线跟踪和既有软件处理；保留慢触/长按正例，不以吞慢触换无隔空 |
| 1/距离、网格地、接大地、shield必能减悬空 | 不能把带覆盖层、边缘场、人体/USB回路及基线处理的响应当通用1/d测距。地与Shield的作用依几何和接法；Shield在官方接近布局中也可增加感应距离。现有SH无连接 | 迁移时保持其余条件作为对照；模块外围差异记录。后续有对应电气证据才另立硬件实验，不在同一次比较中增加地铜/改变地参考 |

## 关键原厂依据及源码边界

- [Infineon TRM 001-91082 Rev.*E](https://www.infineon.com/assets/row/public/documents/30/57/infineon-cy8cmbr3xxx-capsense-express-controllers-registers-trm-additionaltechnicalinformation-en.pdf)：PROX_EN在0x26、仅CS0/1接近配置；敏感度四档及手动FT31–200，ATH/override决定手动字段是否接管。保存字段不代表全部自动运行参数。
- [AN90071 §6.2.2、4.2](https://assets.infineon.com/is/content/infineon/infineon/row/public/documents/30/42/infineon-an90071-cy8cmbr3xxx-capsenser-design-guide-applicationnotes-en.pdf)：按钮DIFF归一化并在255截断；噪声阈值也控制基线更新。FT+HYS的理论最高ON边界为200+31=231，不能拒绝255。官方“信噪比大于5:1”是信号与噪声之比，不是接触信号与触摸门限之比；指南按钮FT示例为信号的80%，不能把“轻触为门限3–5倍”当该芯片的原厂规定。Shield效果依用途与布局。
- [NXP AN3889](https://www.nxp.com/docs/en/application-note/AN3889.pdf)、[AN3891](https://www.nxp.com/docs/en/application-note/AN3891.pdf)、[AN3893](https://www.nxp.com/docs/en/application-note/AN3893.pdf)：MPR测量响应受充电电流/时间、电压及电容影响；基线有方向/触摸状态相关处理；器件也支持接近检测。不能据过滤后的小差值判定原始接近耦合小。

源码基线为src/hw_devices.cpp:503/993/1177/1485和src/chuni_io.cpp:166/307：原生BUTTON_STAT→差值确认→保持/拉伸→游戏0/128；诊断pressureSnap是另一条观察路径，显示连续值不等于HID直接输出它。源码“硬件门限128”等旧注释不是当前实机配置证据，以实际表/模式和原生读回为准。新准入故障语义沿用round90e，未在本轮变更。

只有DIFF=255的片段无法恢复原始幅度；RAW仍变也未必可分。先前[round90f](MBR3116_round90f_离线机理研究与实验收敛.md)有三个中心RAW/BASE/DIFF/CP完全重合元组；[round89z](MBR3116_round89z_两排空间候选对照.md)和[round90b](MBR3116_round90b_时间判据验证.md)是特定规则反例，均保留动作标签及采样限制。上述证据限制现有特征和候选，不能证明所有时空方法均无解。

## 对下一次同板实验的补充

1. 用户断电迁移三片MPR，保持原32寸PCB/主控、覆盖板、供电与装配；接回后先验证USB序号5303284739002C9C、0x5A/B/C地址和芯片种类。若身份不同先停止目标写入。模块外围变化仍是对照变量，不能把差异全部归因于芯片内部。
2. 保留32寸HW2、LED/ToF/Air校准，只审查切换MPR所需字段；不整块复制27寸HW1配置。暂不改变基线算法或加去抖，这样先取得原行为参照。
3. 先用可见按压定位电极与上下两排/32逻辑格，然后覆盖三片读取完整信号及各片控制参数，并检查最终输入。各片顺序采样须有时间/质量标记，不能伪称全板同时。
4. 食指轻触、约4秒慢触、长按以及估计近面悬空分别采集；支持连续接近→接触→保持→释放的机理观察，但不预设接触必有跳变，也不把整段动作确认当精确接触时间。准确动作时刻缺失时不估计接触到HID的毫秒延迟。
5. 重点对照绝对滤波计数、可见基线、差值区间、原生ON和最终输入；基线吸收的因果归属如需加事件记录，另做有界诊断/官方时序审查。先验证MPR慢触和长按均有效，再考虑可移植机制。
6. 新MBR判据先离线面对现有饱和、慢触、多押/slide反例，确认新信息后才影子计算和游戏验收。仍不使用ToF作接触真值、不生成新的128B表，不从压力映射函数推导隔空已根治。
