## 固定位置和操作

真实页为 `http://127.0.0.1:8886/`。正面朝自己，选择USB接口在左或右；**USB接口端为第1竖条**。上半区定义为靠灯条边，下半区靠ToF开口边，不依赖桌面摆放方向。整轮保持方向、起点和落点不变。

1. 一根食指轻贴第8竖条上半区中心。
2. 同一食指轻贴第8竖条下半区中心。
3. 同一食指轻贴第9竖条上半区中心。
4. 同一食指轻贴第9竖条下半区中心。

每组远离4秒→轻贴8秒→移开10秒，确认正确动作或作废；作废重做同点。避开条间缝和上下分界，不重按、不移动寻找响应。**无响应也照实确认正确动作**，以便判断映射未确定，而不是把加力后的不同动作当轻触。每组可补简短备注。四组确认后双手远离并结束；异常可结束保留失败现场。

页面以当前B1抽样显示逻辑格及芯片/电极，不自动给无响应点指定映射。服务端检查计数起点、方向、顺序、当前组确认及hands-clear；确认前不能开始另一组，完成后不能再开始。刷新页面恢复已固定方向、待确认/下一组位置；动作开始须由用户点击，不自动开始。开始前关闭游戏，游戏验收时先结束本页采样。
