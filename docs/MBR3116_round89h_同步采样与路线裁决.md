# round89h 同步采样与路线裁决

2026-10-01。在线仍为1.6.6-beta4/BID round89g；用户复测反馈“检测没有问题”。本轮仅诊断与留档，没有修改固件、成品面板、控制器配置或3116 NVM。

## 方法与有效性

聊天提醒的动作时间偏差由用户指出，旧“食指5 mm全零”组作废；旧聊天轻触不用于此次标定。改用本地页面控制远离4秒、指定动作8秒、移开10秒，每组单独确认或作废。高度从约2–3 mm亚克力顶面算，中央固定点为第17格。

所有姿势统一采用6.0–11.5秒窗口，即动作提示后2秒至结束前0.5秒；不按信号强弱挑选子集。窗口内的全部有效帧纳入，失败帧不补零。完整过渡也保存在原始CSV。该窗口减少反应时间影响，不能保证手已完全稳定；距离为手动估计，不能当作毫米精度标定。

第一轮通过C7读取0x40:CS7的RAW、BASELINE、DIFF，校验身份及SYNC。第二轮在普通模式用C5 level2及B1读取32格归一化DIFF，另用C0/C1记录判定位和失败计数。B1内部为完成帧；B1/C0/C1之间不保证同一采样时刻。正常串口响应、SYNC相等也不证明每帧都是新的电极测量。

## RAW分离结果

6组确认、1组用户作废；以下均为确认组窗口内RAW−BASELINE范围。

|姿势|有效帧|原始增量范围|中位数|
|---|---:|---:|---:|
|食指轻触|90|174–285|260|
|食指悬空5 mm|90|72–106|90|
|食指悬空3 mm|87|103–220|132|
|手掌悬空5 mm，第1次|81|29–441|108|
|手掌轻贴|87|106–495|419|
|手掌悬空5 mm，重采|73|101–186|140|

食指5 mm与该组轻触有间隔，但3 mm已有重叠。第1次手掌悬空随时间明显增大，不能视作恒定高度曲线；即使不据它取上界，重采的186仍高于食指轻触下界174，手掌轻贴下界106也与悬空重叠。相对增量`(RAW−BASELINE)/BASELINE`同样重叠，不能解决此次尺度问题。

因此不把一个RAW门限或Z/F端点部署到全板，也不把饱和的DIFF=255解释为接触。该结论否定的是此次数据上的简单标量分界；不等于证明所有时序或其他原生数据方案都无解。

## 全板轮廓结果

7组均已页面确认；额外手掌3 mm由用户再次明确确认全程未接触。窗口共1790帧。

|姿势|有效帧|非零格数|总DIFF范围|第17格DIFF范围|
|---|---:|---:|---:|---:|
|食指轻触|257|1|167–255|167–255|
|食指悬空3 mm|260|1|201–255|201–255|
|手掌悬空5 mm|261|4–5|337–865|103–205|
|手掌轻贴|265|9|1940–2295|255|
|两指轻触|267|2–3|510–596|255|
|食指悬空5 mm|214|1|86–167|86–167|
|手掌悬空3 mm|266|7–8|1022–1489|201–254|

食指轻触与悬空出现7种完全相同的非零32格向量，包括仅第17格为255、其他全零；该向量在两类中共293帧。集中度、宽度、相邻格比值无法从相同向量中创造区别。现有DIFF32瞬时分类不适合作为全板接触保证。

这组手掌悬空与贴面轮廓存在差异，可以研究某些姿势的辅助抑制，但单次分离不足以推广到不同手掌面积、边缘轻贴、多指及其他位置。两指实际主要活跃格为13和17，另有短暂第三格信号，不能按“格数多即悬空”拒绝正常游戏动作。时序分类尚未验证，也不能通过长等待换取表面的零误触。

读取失败仍存在：各窗口全局门控读取失败增加63–78次。失败时pressure可能保留旧值，该计数不是每个压力通道的有效标记。第17格普通模式悬空3 mm仍ON 255/260帧，轻触ON 225/257帧；这些跨事务统计仅描述采样结果，不能当物理误触率、漏触率或因果证据。后续须细分传输、SYNC与超龄，才能可靠评估接触短暂中断。

## 下一步路线

1. **停止部署已无可靠分界的简单门控。** 保留round89g完成帧发布；不增加扫描等待，不据本组数据把门限抬高到“刚好没悬空”。当前原生最低按钮灵敏度及FT=200、ATH对照已见此前记录。
2. **探索原生Proximity作为邻格参考。** [TRM Rev. E §1.5.30/33–36](https://www.infineon.com/assets/row/public/documents/30/57/infineon-cy8cmbr3xxx-capsense-express-controllers-registers-trm-additionaltechnicalinformation-en.pdf)定义仅CS0/CS1可转Proximity，触摸门限62–65000，扫描分辨率12–16位。三片映射只覆盖第2/4/18/20/29/31格。邻格更宽信号能否补充第17格轻触/悬空的区别是待验证假设，不能宣称六个输入足以测整板高度。
3. **局部实验先诊断，后谈成品。** 从已回读、校验的原表只修改原厂明确定义的模式/分辨率字段及原厂CRC；保留恢复文件。先在配置诊断模式读取宽信号，比较相邻固定点的轻触、3/5 mm悬空与手掌，随后完整恢复。现有按钮管线会限制超过255的量，不能把实验表直接当正常游戏配置。未实施此实验。
4. **同时验证信息与时延。** [原厂Host API](https://www.infineon.com/dgdl/Infineon-CY8CMBR3xxx_Host_APIs-ApplicationNotes-v09_00-EN.zip?fileId=8ac78c8c7cdc391c017d0723702846a2)要求切换调试SENSOR_ID后等待刷新间隔；C7的40 ms诊断等待不能放入游戏扫描。普通按钮全板RAW轮询、较高Proximity分辨率都须先算时延并实测多指。全板可靠性还需每芯片采样有效性及失败原因证据。
5. **目标边界。** 现有数据不支持仅调整按钮寄存器或DIFF/Z/F，便可靠实现32格统一的物理“零距离接触”。若原生参考信号也无裕量，应明确固件可做的是条件性的误触抑制及信号阈值标定，不能把其包装为毫米距离或严格零悬空。
