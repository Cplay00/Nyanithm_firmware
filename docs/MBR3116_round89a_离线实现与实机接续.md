# MBR3116 round89a：离线实现与实机接续

日期：2026-10-01。候选固件 `1.6.6-beta1 / hw_v1 / BID=round89a`。

本阶段实现无需用户配合采样的部分。没有连接串口、刷写设备、保存设备配置或编程 MBR3116 NVM。实验性持续信号门默认关闭；这次交付不代表隔空触发已经解决。

此前的官方资料、实机只读证据和硬件替代路线见 [技术路线](MBR3116_可调触发距离技术路线_20260930.md)。其中“本轮未修改源码”是上一阶段的范围说明；本文记录后续实现。

## 已实现的运行行为

旧 `mbrTouchGate` 只在新触摸验证时参与，已确认触摸可能继续保持，邻格 slide 还会放宽它。本次增加独立持续门：每个映射电极都要通过原生 `BUTTON_STAT` 与 ON/OFF 信号边界，保持期间也检查；严格拒绝后清除确认、快路径、拉伸、dip 和 sticky 状态。邻格优化不能越过这个门。

读取使用原厂 Host API `CY8CMBR3xxx_ReadDiffCounts` 的 B9..DB、35B 结构，复用现有 I2C STOP-read 和 Pico SDK：先验证整次传输与两端 SYNC，再发布16个小端 DIFF；同步撕裂最多读两次，短读/传输错误立即失败，失败不发布部分数组。[原厂 Host API](https://www.infineon.com/dgdl/Infineon-CY8CMBR3xxx_Host_APIs-ApplicationNotes-v09_00-EN.zip?fileId=8ac78c8c7cdc391c017d0723702846a2)

运行缓存5ms到期轮询；全部芯片读完后，在同一主机时刻检查15ms读取年龄。失效、超龄、原生 OFF、非法按钮 DIFF>255 均在该次判定中拒绝。这里的“年龄”是主机读取开始时间，**不是芯片新扫描标识**；相同 SYNC 可重复出现，也不意味着取得了新样本。实际刷新、端到端释放延迟和 I2C 负载仍需实机测量。

关闭时沿用旧触摸行为，不增加持续门的35B读；MPR不启用此门。`hwVer=1/2` 三芯片和 `hwVer=3/4` 双芯片映射均覆盖。参数/布局/启用状态变化会清除缓存及下游历史，不能继承旧已确认状态。运行不依赖面板连接或 C5 会话。

同时修复了跨核读取的原有漏洞：稳定奇数 generation 在等待超时后不能判为成功。HID跳过该次报告，GET_INPUT保留上一完整帧，DEBUG_CHAIN保留上一完整46B帧（首次超时为零负载）。

## 零点、满点和兼容性

参数是按钮 DIFF 的0–255信号刻度。Z为归一化零点，F为满点；Z<F，ON为1–100%，OFF为0至ON以下的整数百分比。

```text
ON_count  = Z + ceil((F-Z) × ON% / 100)
OFF_count = Z + floor((F-Z) × OFF% / 100)
未激活：DIFF >= ON_count 才允许候选触摸
已激活：DIFF <= OFF_count 立即撤销候选触摸
```

例如 Z=100/F=250/ON=80%/OFF=60%，得到ON=220、OFF=190。此数字仅用于解释逻辑，**不是本设备的推荐标定值**。

这些点控制持续门的阈值范围，不是物理毫米或压力。游戏二值上报及现有压力上报模式保持原语义；C5原始诊断仍显示原生DIFF，没有偷偷用两点映射替换采样单位。

此门与原生 `BUTTON_STAT`、现有逐键阈值和旧验证门取 AND。把新ON调低不能绕过这些更严格的门，也不能扩展芯片原生触发距离。全局profile只适合各区域具有共同可分区间的情况；每键两点及扩展Flash结构尚未实现。

`controller_config`继续128B，版本仍0x02，CFG_SET仍单独发送命令再发送128B。旧字段偏移不变，新门占原reserved中8B：

| 字节 | 内容 |
|---|---|
| 91 | magic 0xD6 |
| 92 | profile version 1 |
| 93 | flags，仅bit0启用 |
| 94/95 | Z/F |
| 96/97 | ON%/OFF% |
| 98 | 0xA7 XOR字节91..97 |
| 99..126 | 剩余28B reserved |
| 127 | 整块原有XOR |

旧全零reserved、签名/版本/check/范围错误或未知flag不会启用。切MPR会清除启用标志，保留合法两点并重算校验。面板要求匹配的 `NYANFW1` 版本/变体签名、固件≥1.6.6-beta1及BID≥round89a；每次握手重新确认，超时或畸形响应撤销能力。

## 面板和标定评估

新增“实验性持续信号门”独立配置区，默认关闭，展示实际ON/OFF计数边界。非法参数不能保存。新门保存只写控制器配置，不更改芯片寄存器表；现有另行编辑的芯片表仍按原保存机制处理。

纠正 HYS 为ON≥FT+HYS、OFF≤FT−HYS，区分编辑表ATH状态与已从芯片读回的状态，删除未标定的DIFF→毫米换算。原单悬空峰值向导改为仅观察，禁自动生成/应用阈值。

新增同单位、明确目标区域的两类样本评估函数 `evaluateMbrCalibration`：检查样本数、区域命中、接触全零、类别重叠、跨区域共同区间和噪声裕量。无效数据不会生成建议；有效建议仍默认关闭、不自动写设备。当前自动两点建议保守拒绝裁剪/饱和样本，意味着不能自动建立完整无裁剪标定；单独接触达到255并不证明悬空与接触一定不可分。手动F=255合法，但须单独验证。

此评估函数尚未接成完整采样向导；下一阶段先补可靠定位及两类数据，再确定是否继续建设向导。不能用之前静态轻触全零的三通道数据启用全板profile。

Mock现在区分RAM与CFG_SAVE快照；未保存CFG_SET不会跨新端口持久化。端口枚举保持同一活动实例，重启后从保存快照创建新实例；两处CFG_SET都按新profile的固件规则sanitize并重算整块XOR。真实串口CFG_SET双写和纯waitForLine保持。

下一阶段需要用户在场：

1. 备份/确认当前设备配置，刷候选并核对精确BID；先保持新门关闭验证输入、灯光、ToF、保存重启/回读及0xCE。
2. 先在普通扫描状态确认物理区域映射，记录全板原始DIFF与最终输入，避免预选错键。C2当前是MPR专用，不能拿来采MBR；C7仅用于固定电极RAW/BASELINE研究，不是全板高速采样。
3. 用户指定禁止触发高度，用可重复间隔片/手姿，按“手远离→悬空→轻触→抬回悬空”采短窗口、重复多次。至少覆盖食指、手掌、另一格已接触、多指、慢靠近、长按与slide；获取有效接触，而非全零。
4. 在同一设置下先判是否可分，再做ATH单变量A/B。任何芯片配置实验均从真实128B备份出发，对照原厂字段/工具，只改已核实项，逐片保存/重启/复读CRC，失败恢复；不生成猜测寄存器表。
5. 可分时才选择保守全局profile，并实测HID误触、漏触、释放与延迟。不分或无法满足手感时按原路线转逐区域独立接触证据/互电容样机，不继续把去抖堆成“距离测量”。
